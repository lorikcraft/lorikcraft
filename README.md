# LoRiK Craft — Digital Studio Website

Responsive multi-page portfolio built with semantic HTML, custom CSS and lightweight JavaScript.

## Pages
- Home: studio overview, services and featured projects
- Services: capabilities and workflow
- Work: Maisha’s Closet, Amber Bean and Storage Solution
- Contact: WhatsApp enquiry preparation

## Local preview
Open index.html in a browser or serve the repository root with a static web server.

## Vercel
Static site; no build command or output directory is required. Deploy from the repository root.

## Review notes
- Contact form prepares a WhatsApp message; it does not store submissions.
- Project descriptions are qualitative and avoid unverified performance claims.
- Google Fonts load remotely.
